# 照片逆时针旋转

[English](README.en.md)

一款轻量 Android 应用，可从系统照片选择器选图，也可从相册分享单张或多张照片到应用，再旋转 90° 或 180°，选择覆盖原图或另存到 `Pictures/PhotoRotator`。

## 功能

- **旋转方向**：逆时针 90 度（默认）、顺时针 90 度或 180 度。
- **保存方式**：覆盖（默认）会先申请 Android 的照片修改授权，再替换原照片内容；另存新图会将结果写入 `Pictures/PhotoRotator`。
- **覆盖后的时间**：默认在覆盖后恢复原文件修改时间，也可选择更新为当前时间；保存后重新扫描照片并确认相册修改时间已同步。此选项只在选择覆盖时显示，拍摄时间保留。
- **设置与关于**：可保存默认旋转方向、保存方式和覆盖后的时间戳选项；主界面和“关于”页面显示软件版本与构建时的 7 位 Git commit ID。Debug 包包含未提交修改时会加上 `-dirty`，日常调试无需提交代码。“关于”页面也显示作者信息。
- **EXIF 信息**：旋转时保留常用 EXIF 信息，包括 GPS、相机厂商/型号及拍摄时间。图片像素会重新编码，专有厂商数据和嵌入式缩略图可能无法保留。覆盖原图前如写入失败，应用会尝试恢复原文件。
- **批量处理**：当前最多选择 50 张照片，逐张显示处理结果。已选照片可预览、展开查看并单独剔除；成功覆盖后，预览从本机原图重新生成。
- **从相册分享**：分享单张或多张图片后会自动选中，仍需手动确认旋转。一次分享超过 50 张会整批拒绝，原有选择保持不变。其他应用提供的照片可能不含完整 EXIF；无法确认本机原图时只能另存新图。
- **再次选择**：支持预选的系统会在照片选择器中保留当前勾选；旧系统会将新选择追加到当前列表并去重。
- **系统照片选择器**：不需要选择文件夹，也不要求授予整个存储目录的访问权。云端且尚未下载到本机的照片无法旋转。

处理时会在应用缓存中临时保存原图和旋转结果；JPEG/WebP 使用 95% 质量，需预留足够缓存空间。已有写入权限的照片会直接旋转；Android 12 及以上可在系统中开启媒体管理授权，免除覆盖时的逐次确认，设置页提供授权入口。未开启授权或使用 Android 11 时，系统仍可能要求确认。完成后会显示短暂结果提示，并在页面保留成功或失败信息。

## 构建

- 应用 ID：`dev.stone.photorotator`
- 版本：`1.0.0`（versionCode `3`）
- 最低 Android 版本：Android 11（API 30）
- 编译 SDK：API 35
- Java：11

在 Android Studio 打开项目，或在已安装 Android SDK 的环境运行：

```sh
./gradlew assembleDebug
```

APK 输出位置：`app/build/outputs/apk/debug/app-debug.apk`。

## 实现说明

系统照片选择器可能返回虚拟路径或经过处理的显示名称。对于 Android 本机照片选择器 URI，应用从 URI 中读取原始 MediaStore 图片 ID，并确认本机图片存在，再访问该 ID 对应的原图；不会仅凭名称猜测照片。Android 文档 URI 会尝试转换为 MediaStore URI。其他分享 URI 会按名称查找本机照片，并核对原始路径或文件内容。相册分享相机照片时即使删减了 EXIF、改变了文件大小，也可通过相同的 JPEG 图像数据确认原图；只有唯一匹配时才允许覆盖。无法确认本机原图时，另存新图会读取分享应用实际提供的内容与 EXIF。

EXIF 处理使用 AndroidX `ExifInterface`。写入前后会比较已复制的常用 EXIF 字段，并将新图方向设为正常；保存新图失败时清理未完成的副本，覆盖失败时尝试恢复原文件。
