# 照片逆时针旋转

[English](README.en.md)

一款轻量 Android 应用，从系统照片选择器选择一张或多张图片，可旋转 90° 或 180°，并选择覆盖原图或另存到 `Pictures/PhotoRotator`。

## 功能

- **旋转方向**：逆时针 90 度（默认）、顺时针 90 度或 180 度。
- **保存方式**：另存新图（默认）会将结果写入 `Pictures/PhotoRotator`；覆盖会先申请 Android 的照片修改授权，再替换原照片内容。
- **EXIF 信息**：旋转时保留常用 EXIF 信息，包括 GPS、相机厂商/型号及拍摄时间。图片像素会重新编码，专有厂商数据和嵌入式缩略图可能无法保留。覆盖原图前如写入失败，应用会尝试恢复原文件。
- **批量处理**：当前最多选择 50 张照片，逐张显示处理结果。已选照片可预览、展开查看并单独剔除。
- **再次选择**：支持预选的系统会在照片选择器中保留当前勾选；旧系统会将新选择追加到当前列表并去重。
- **系统照片选择器**：不需要选择文件夹，也不要求授予整个存储目录的访问权。云端且尚未下载到本机的照片无法旋转。

处理时会在应用缓存中临时保存原图和旋转结果；JPEG/WebP 使用 95% 质量，需预留足够缓存空间。覆盖操作需要在系统确认框中授权。

## 构建

- 应用 ID：`dev.stone.photorotator`
- 版本：`0.9.0`（versionCode `2`）
- 最低 Android 版本：Android 11（API 30）
- 编译 SDK：API 35
- Java：11

在 Android Studio 打开项目，或在已安装 Android SDK 的环境运行：

```sh
./gradlew assembleDebug
```

APK 输出位置：`app/build/outputs/apk/debug/app-debug.apk`。

## 实现说明

系统照片选择器可能返回虚拟路径或经过处理的显示名称。对于 Android 本机照片选择器 URI，应用从 URI 中读取原始 MediaStore 图片 ID，并核对文件大小和 MIME 类型，再访问该 ID 对应的本机原图；不会仅凭名称猜测照片。其他 URI 会使用文件名、大小和相对目录进行匹配，并拒绝不唯一的结果。

EXIF 处理使用 AndroidX `ExifInterface`。写入前后会比较已复制的常用 EXIF 字段，并将新图方向设为正常；保存新图失败时清理未完成的副本，覆盖失败时尝试恢复原文件。
