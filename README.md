# 照片逆时针旋转

一款轻量 Android 应用，从系统照片选择器选择一张或多张图片，逆时针旋转 90° 并保存到 `Pictures/PhotoRotator`。原图始终保留。

## 功能

- **逆时针旋转并保存副本**：旋转像素并重新编码，JPEG 使用 95% 质量；此模式不保证保留全部 EXIF 信息。
- **逆时针旋转（保留 EXIF）**：支持 JPEG、PNG、WebP。应用读取本机原图，在副本中只更新 EXIF 方向标记，不重新编码图像像素，并校验 GPS、相机厂商/型号及拍摄时间等字段。此模式需要读取照片和照片位置信息的权限；首次使用时会申请。原图不可访问或校验失败时，不会生成副本。
- **批量处理**：一次选择多张照片，逐张显示处理结果。
- **系统照片选择器**：不需要选择文件夹，也不要求授予整个存储目录的访问权。云端且尚未下载到本机的照片可能无法使用保留 EXIF 模式。

保留 EXIF 模式会将照片临时复制到应用缓存再写入副本，需预留与照片文件大小相近的缓存空间。少数图片应用不读取 EXIF 方向标记，可能无法按旋转后的方向显示图片。

## 构建

- 应用 ID：`dev.stone.photorotator`
- 版本：`0.9.0`（versionCode `2`）
- 最低 Android 版本：Android 11（API 30）
- 编译 SDK：API 35
- Java：11

在 Android Studio 打开项目，或在已安装 Android SDK 的环境运行：

```sh
./gradlew assembleDebug
```

APK 输出位置：`app/build/outputs/apk/debug/app-debug.apk`。

## 实现说明

系统照片选择器可能返回虚拟路径或经过处理的显示名称。对于 Android 本机照片选择器 URI，应用从 URI 中读取原始 MediaStore 图片 ID，并核对文件大小和 MIME 类型，再访问该 ID 对应的本机原图；不会仅凭名称猜测照片。其他 URI 会使用文件名、大小和相对目录进行匹配，并拒绝不唯一的结果。

保留 EXIF 的处理使用 AndroidX `ExifInterface`。写入前后会比较 GPS 坐标、GPS 时间、相机厂商/型号和原始拍摄时间；失败时清理未完成的副本。应用不覆盖原图。
